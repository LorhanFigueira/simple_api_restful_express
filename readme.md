# RESTful API for managing students, courses, and enrollments 🖥️​

# Description 📕

Management of students, courses, and enrollments, with CRUD funcionality for each.

# Tecnologies 🧑‍🔧

- NodeJS
- Typescript
- Express
- TypeORM
- Postgres
- Yup

# Functions 🤖

## Student 👩‍🎓​

- Create a Student
- Get a Student List
- Get a Student by ID
- Edit an existing Student
- Delete an existing Student

## Course ​💼​

- Create a Course
- Get a Course List
- Get a Course by ID
- Edit an existing Course
- Delete an existing Course

## Enrollment 📝​

- Create an Enrollment
- Get an Enrollment List
- Get an Enrolment by ID
- Edit an existing Enrollment
- Delete an existing Enrollment

# Installation 🛜​

Clone repository:

```bash
    git clone https://github.com/LorhanFigueira/simple_api_restful_express.git
```

### Docker only:

```bash
    docker compose up --build -d
```

### Manually:

```bash
    npm install
```

After the installations, you need to create .env file, insert all the configurations found in **env.example** into it, and then do the folllowing:

```bash
    docker compose up -d
    npm run dev
```
